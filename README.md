# EngagePilot Releases

EngagePilot（macOS用。LinkedIn・X・Threadsでの専門的な発信・対話を支援するアプリ）の配布物（.dmg）だけを公開するリポジトリです。

- このリポジトリにはソースコードは含まれません。ソースコードは別の非公開リポジトリで管理しています。
- アプリ内の「設定 → アップデート」「メニューバー → アップデートを確認」は、このリポジトリの [Releases](../../releases) を参照して新しいバージョンの有無を確認します。
- 最新版は [Releases](../../releases/latest) からダウンロードできます。

## インストール方法

1. [最新のリリース](../../releases/latest) から `EngagePilot-x.y.z.dmg` をダウンロードする
2. ダブルクリックしてマウントし、`EngagePilot.app` を `Applications` フォルダへドラッグする
3. 初回起動時に「開発元が未確認のため開けません」と表示された場合は、Finderで `EngagePilot.app` を右クリック（またはControlキーを押しながらクリック）→「開く」を選んでください
